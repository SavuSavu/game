## Files

- `readme.md` — project overview and development roadmap.
- `index.html` — the starter website published with GitHub Pages.
- `.nojekyll` — serves the site as plain static files.

## Local preview

Run from the repository folder:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publishing

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the website.
